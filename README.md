# 📸 Photography Website

A beautifully designed responsive photography website built with **HTML, CSS, and Tailwind CSS**, showcasing elegant layouts, inspirational quotes, and project galleries. The site highlights the art of photography and the founder’s story with modern UI practices.

---

## 🔗 Live Demo

👉 [Click Here to Explore the Live Demo](https://photography-website-using-html-tailwind-css.vercel.app/)  

---

## 📌 Project Highlights

- 📷 Eye-catching landing page for photography lovers.
- ✍️ Inspirational quote with stunning images.
- 👤 Founder spotlight section.
- 🖼️ Dynamic layout for recent photography projects.
- ✅ Clean, responsive, and elegant UI.
- 🌐 Fully responsive across desktop, tablet, and mobile.

---

## 🧩 Features

- Responsive navbar with hover animations.
- Grid layout of recent photo projects.
- Custom font integration (Google Fonts).
- Minimalist yet aesthetic design using Tailwind CSS.
- Footer with navigation and extra sections.
